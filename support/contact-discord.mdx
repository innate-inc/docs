The fastest way to get help is the Innate Discord — the team and other MARS owners are active there daily.

* Discord: [Join the Innate community](https://discord.com/invite/KtkyT97kc7)
* Email: [axel@innate.bot](mailto:axel@innate.bot)

When reporting an issue, include these four things and you'll get a useful answer much faster:

* robot ID
* software version
* exact error message
* what you were doing right before the issue
