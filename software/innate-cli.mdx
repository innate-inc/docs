---
title: "Innate CLI"
description: "Reference for the innate command on the robot"
---

Run `innate` on the robot over SSH. `in8` is a shorter alias. Running `innate` alone prints the version, mode, and ROS status.

## Services

| Command | Description |
| --- | --- |
| `innate service start` | Start all nodes in tmux |
| `innate service stop` | Stop all nodes |
| `innate restart` | Restart all nodes. Same as `innate service restart`. |
| `innate view` | Attach to the node session. Same as `innate service view`. |

## Build

| Command | Description |
| --- | --- |
| `innate build [pkg ...]` | Build the workspace or named packages. Stops and restarts nodes if they're running. |
| `innate build release [pkg ...]` | Build with `CMAKE_BUILD_TYPE=Release` |
| `innate clean` | Delete `build/`, `install/`, and `log/` |

## Skills

| Command | Description |
| --- | --- |
| `innate skill list` | List loaded skills |
| `innate skill type <id> [--json]` | Show a skill's parameters |
| `innate skill run <id> [@key=value ...]` | Run a skill. `--timeout <sec>` limits the wait (default: no limit). |

```bash
innate skill run local/victory_spin @spins=2
```

## Updates

| Command | Description |
| --- | --- |
| `innate update check` | List available updates |
| `innate update apply [version]` | Install the latest or a given version. `-y` skips prompts, `-b` runs in the background. |
| `innate update status` | Show the installed version and service health |
| `innate update reinstall` | Redo post-update setup without changing version |

Put `--dev` before the subcommand to allow pre-releases and branches, for example `innate update --dev apply main`.

## Other

| Command | Description |
| --- | --- |
| `innate diag` | Check servos, PCB, LiDAR, cameras, and speaker |
| `innate volume [0-100]` | Show or set speaker volume |
| `innate foxglove start \| stop \| status` | Control the [Foxglove](/software/foxglove-setup) bridge |
