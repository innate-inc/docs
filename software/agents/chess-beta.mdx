MARS can play a full game of chess with its arm. The robot plays White. This page covers `chess_agent` in OS 0.7.1.

## Set up

<Callout icon="image" color="#7569FD">
  **Image to make: Chess setup.** Top-down photo of MARS in front of the board, showing how far away the board sits, which side faces the robot (rank 8 closest or farthest), and the A8 and H8 corners labelled.
</Callout>

1. Put the board in front of the robot, in a spot where it won't move.
2. Add a [Gemini API key](https://aistudio.google.com/api-keys) for move detection:

   ```bash
   echo "GEMINI_API_KEY=your_key" > ~/innate-os/workspace/innate_skills/.env.scan
   ```

## Calibrate the board

Calibrate once, and again whenever the board moves. You place the gripper over two squares and MARS computes the rest.

<Steps>
  <Step title="Make the arm limp">
    Run the skill `arm_utils` with `command=torque_off`.
  </Step>
  <Step title="Record A8">
    Move the gripper by hand to the center of `A8`, then run `recalibrate_manual` with `corner=A8`.

    <Frame><img src="/images/main/software/agents/chess-calibration-a8-end-effector.jpg" width="360" /></Frame>
  </Step>
  <Step title="Record H8">
    Move the gripper to the center of `H8` and run `recalibrate_manual` with `corner=H8`.
  </Step>
  <Step title="Lock the arm">
    Run `arm_utils` with `command=torque_on`. The corners are saved to `~/board_calibration.json`.
  </Step>
</Steps>

Run these from the app's **Skills** tab, or with `innate skill run` (see [Run a skill manually](/software/skills#run-a-skill-manually)). The chess agent can also walk you through them.

<Tip>
  To check accuracy, put a pawn on `A4` and run `pick_up_piece_simple(square="A4", place_square="H5", piece="pawn", is_capture=False)`. If it misses, calibrate again.
</Tip>

## Play

Start `chess_agent` and ask for a new game. You play Black. The robot starts without its `a1` rook as a handicap.

After each of your moves, tell the robot it's its turn. It looks at the board to detect your move, picks its reply, moves the piece, and says what it played. The game state is saved in `~/chess_game_state.json`.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Move detection fails | Check the Gemini key file, and that nothing blocks the wrist camera. |
| Pieces land off-center | Calibrate the board again. |
| Reset fails with a calibration error | Calibrate the board first. |
| Arm stops responding | Run `arm_utils` with `command=reboot_arm`. |
