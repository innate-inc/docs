title: "Example: Microphone"
---

Innate Robots are designed with extensibility in mind.

MARS, in particular, can easily be augmented with a $50 microphone to be able to listen to you (see tested components in [Extending MARS](/robots/mars/extending-mars))

By default, a `MicroInput` device is available on MARS. If you have a microphone plugged in and are triggering an agent using it, you will be able to talk directly to MARS. See below the relevant part of the code in the hello world agent (same as in [Anatomy of an Agent](/software/agents/definitions)).

```innatepy
from inputs.micro_input import MicroInput

def get_inputs(self) -> list[InputRef]:
    # This agent can use an integrated microphone input to hear the user
    return [MicroInput]
```

The code for this input device is available in the innate-os repository at [`workspace/inputs/micro_input.py`](https://github.com/innate-inc/innate-os/blob/main/workspace/inputs/micro_input.py).
