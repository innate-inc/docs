This section is for developers who want to go beyond the Agent/Skill abstraction and work directly with the underlying systems.

**Most developers don't need this.** Agents, Skills, and Inputs cover 90% of use cases. This section is for those who want low-level control or need to debug system internals.

## Prerequisites

To work at this level, you should be comfortable with:

- SSH access to your robot ([Connecting via SSH](/robots/mars/connecting-via-ssh))
- Basic ROS2 concepts (topics, services, actions)
- Command-line tools (`ros2 topic`, `ros2 service`, etc.)
- Python or C++ for writing ROS2 nodes
