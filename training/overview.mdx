You teach MARS a task by doing it yourself a few dozen times, with the leader arm or the phone app. A policy learns from those demonstrations. There are two ways to train it, and they end in different places:

| | Innate cloud | LeRobot |
| --- | --- | --- |
| **Model** | [ACT](https://arxiv.org/abs/2304.13705) | Any LeRobot policy: ACT, Diffusion Policy, SmolVLA, π0, and more |
| **Trains on** | Innate's GPUs, started from the apps | Your own NVIDIA GPU or Apple Silicon, from the terminal |
| **You end with** | A **skill** on the robot | A policy checkpoint on your computer |
| **Runs** | On the robot, without your computer | From your computer, streaming actions to the robot over the network |
| **Agents and code can call it** | Yes, like any other [skill](/software/skills) | No. It isn't a skill, so agents and other skills can't use it. |
| **Use it when** | You want a skill the robot can use on its own | You want to try other models, or do research |

Both start from the same recordings: a dataset you record in the apps can also go to Hugging Face for LeRobot.

<Tip>
  For a motion that never changes, like a wave, record it once as a [replay skill](/software/skills/policy-defined-skills) instead of training.
</Tip>

## Train in the Innate cloud

Record a dataset and start a run from the app. Innate trains an ACT policy, and the robot downloads it automatically and runs it as a skill. You don't need a GPU or any ML setup.

The policy looks at both cameras and the arm's joints, and outputs arm and base commands 25 times a second.

<Steps>
  <Step title="Record a dataset">
    Teleoperate the task 30 or more times. [Record a dataset →](/training/data-collection)
  </Step>
  <Step title="Train">
    Launch a run with the default settings. [Train in the cloud →](/training/train-act-policy)
  </Step>
  <Step title="Deploy and iterate">
    Run the skill, see where it fails, add data, retrain. [Deploy and iterate →](/training/deploy-trained-skill)
  </Step>
</Steps>

Every step works in both the phone app and the web app:

| Step | Phone app | Web app |
| --- | --- | --- |
| Record | **Skills → Physical → Record** tab | **Collect** page |
| Train | **Train** tab | **Training** page |
| Monitor | **Runs** tab | **Running now** card |
| Download | **Completed** tab | Automatic |

## Train with LeRobot

[LeRobot](https://github.com/huggingface/lerobot) is Hugging Face's robot learning library. MARS works with its standard commands: you record or upload a dataset, train any of its policies on your own GPU, and run the policy with `lerobot-rollout` while your computer stays connected to the robot. [Train with LeRobot →](/training/lerobot)
