title: "Training Overview"
description: "Teach MARS a manipulation skill by demonstrating it"
---

You show MARS a task with the leader arm a few dozen times. Innate's cloud GPUs train a policy from those demonstrations, and the robot downloads it as a skill. You don't need a GPU or any ML setup.

<Callout icon="image" color="#7569FD">
  **Image to make: Training pipeline.** Horizontal diagram with five steps and rough durations: Record 30+ demonstrations with the leader arm → Upload (automatic) → Train in the cloud (1–3 h) → Download to the robot (automatic) → Run as a skill from the app or an agent. Replaces an ASCII diagram.
</Callout>

The model is [ACT (Action Chunking with Transformers)](https://arxiv.org/abs/2304.13705). It looks at both cameras and the arm's joints, and outputs arm and base commands 25 times a second.

## Steps

<Steps>
  <Step title="Record a dataset">
    Teleoperate the task 30 or more times. [Record a dataset →](/training/data-collection)
  </Step>
  <Step title="Train">
    Launch a run with the default settings. [Train a policy →](/training/train-act-policy)
  </Step>
  <Step title="Deploy and iterate">
    Run the skill, see where it fails, add data, retrain. [Deploy and iterate →](/training/deploy-trained-skill)
  </Step>
</Steps>

Every step works in both the phone app and the web app:

| Step | Phone app | Web app |
| --- | --- | --- |
| Record | **Skills → Physical → Record** tab | **Collect** page |
| Train | **Train** tab | **Training** page |
| Monitor | **Runs** tab | **Running now** card |
| Download | **Completed** tab | Automatic |

<Tip>
  For a motion that never changes, like a wave, record it once as a [replay skill](/software/skills/policy-defined-skills) instead of training.
</Tip>
