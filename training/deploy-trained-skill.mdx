## Get the model on the robot

If the robot is on when a run finishes, the model downloads and activates by itself. In the phone app, you can also tap **Download** on the run in the **Completed** tab.

Once active, the skill is available everywhere. Downloading a different run of the same skill replaces the active model.

## Test it

Run the skill by hand from the web app's **Teleop** page or the phone app's **Manual Control** (see [Run a skill manually](/software/skills#run-a-skill-manually)). The arm moves to its start pose, then the policy takes over.

Make the first test easy: same robot position, object, and lighting as when you recorded. If it fails there, the problem is the data, not the scene.

Then add it to an agent like any skill:

```innatepy
from innate_skills.pick_up_cup import PickUpCup   # your trained skill

def get_skills(self) -> list[SkillRef]:
    return [PickUpCup, NavigateToPosition]
```

## Fix what fails

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| Barely moves | Too few episodes, or varied start poses | Record more, from a consistent start pose |
| Overshoots the target | Jerky demonstrations | Re-record smoothly, or raise chunk size |
| Starts well, then drifts | Too little variation | Add episodes with the object shifted slightly |
| Fails after moving things | Every episode used the same spot | Record with 2–5 cm of position spread |
| Grasps at the wrong time | Inconsistent grasp timing | Close the gripper at the same moment each time |
| Ignores the object | Lighting or background changed | Record in the current conditions |

The most reliable fix is more data. Record 20–30 episodes of the failing case and retrain; new episodes add to the existing dataset. Once it works, add variation step by step (a new position, a different color, other lighting) and record 10–20 episodes each time it breaks.
