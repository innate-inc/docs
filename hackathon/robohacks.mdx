Welcome to RoboHacks. Do these three things first.

<Steps>
  <Step title="Join the Wi-Fi">
    Robots are set up for the **Robot** network. The password is pinned on [Discord](https://discord.com/invite/KtkyT97kc7). Put your laptop and phone on it too.
  </Step>
  <Step title="Update your robot">
    [SSH in](/robots/mars/connecting-via-ssh) and run `innate update apply`.
  </Step>
  <Step title="Get your service key">
    **Robot track:** copy `INNATE_SERVICE_KEY` from `~/innate-os/.env` on your robot. **Sim track:** ask in **#innate-cloud-infra** on Discord. One key per team.
  </Step>
</Steps>

## Resources

| Resource | What's in it |
| --- | --- |
| [robohacks-utils](https://github.com/innate-inc/robohacks-utils) | HDF5 to LeRobot converter, and STEP files of MARS |
| [MARS URDF](https://github.com/innate-inc/innate-os/tree/main/ros2_ws/src/mars_bot/mars_description) | Robot description. Sim-track submissions must use it. |
| [Innate OS](https://github.com/innate-inc/innate-os) | All robot software |
| [GraspGen](https://github.com/innate-inc/GraspGen) | Grasping any object with depth, controlled over rosbridge (port 9090) |
| [UniNaVid client](https://github.com/innate-inc/innate-os/tree/main/ros2_ws/src/cloud/innate_uninavid) | Vision-language navigation, used by the `navigate_with_vision` skill |
| [W&B dashboard](https://wandb.ai/vignesh-anand/act-simple/table) | Training runs |

The leader arm works only with Android phones. We have spares to lend.
