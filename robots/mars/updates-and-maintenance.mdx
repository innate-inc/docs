## Update Innate OS

The app tells you when an update is available. To install it, [SSH into the robot](/robots/mars/connecting-via-ssh) and run:

```bash
innate update check    # see what's available
innate update apply    # install the latest stable version
innate update status   # confirm the installed version
```

Services restart during the update, so the robot is unresponsive for a moment. A new OS may also need a newer [app](/robots/apps). If the release notes mention depth changes, redo [stereo depth calibration](/robots/mars/stereo-depth-calibration).

## Charge the battery

<Warning>
  LiPo batteries are dangerous if charged wrong. Never charge without the white balance connector plugged in. If the battery is swollen, stop using it and contact us.
</Warning>

<iframe width="100%" height="420" src="https://www.youtube.com/embed/SnGpyMkS0WM" title="Charging the battery" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen />

<Callout icon="image" color="#7569FD">
  **Image to make: Charger connections.** Close-up photo of the charger with the battery plugged in, the white balance connector in the `3S` port circled, and the display showing LiPo 3S mode.
</Callout>

1. Connect the battery to the included charger, with the white balance connector in the `3S` port.
2. Check the voltage reads between **10.5 V and 12.6 V**.
3. Set battery type to **LiPo** and cells to **3S**.
4. Hold **Enter** until prompted, then confirm to start.

The app shows **Battery Low** below 10.53 V. Park the robot and charge it, and don't run updates on a low battery.

## Shut down

Always shut down before unplugging. Cutting power can corrupt the disk.

```bash
sudo shutdown now
```

Unplug once the LED turns off.

## Change the voice

MARS speaks with [Cartesia](https://cartesia.ai/). Pick a voice in their library, or clone one from 10 seconds of audio, and copy its voice ID. Add it to `~/innate-os/.env`:

```bash
CARTESIA_VOICE_ID="your-voice-id"
```

Then run `innate service restart`.

<Accordion title="Set the voice per node instead">
  In [`config/settings.yaml`](/software/configuration), set `cartesia_voice_id` under both `brain_client_node` (chat replies) and `input_manager_node` (realtime voice). Values here override `.env`.
</Accordion>
