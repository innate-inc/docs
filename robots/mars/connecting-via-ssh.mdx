---
title: "Connect via SSH"
description: "Open a terminal on the robot over Wi-Fi, Ethernet, or USB-C"
---

| | |
| --- | --- |
| **Username** | `jetson1` |
| **Password** | `goodbot<number>`, for example `goodbot21` for MARS the 21st. Plain `goodbot` if your robot has no number. |
| **Hostname** | Shown in the app under **Configuration → WiFi**, for example `mars-the-21st.local` |

## Wi-Fi

Put your computer on the same network as the robot, then:

```bash
ssh jetson1@mars-the-21st.local
```

If the hostname doesn't resolve, use the IP address from the same app screen.

To skip the password from now on:

```bash
ssh-copy-id jetson1@mars-the-21st.local
```

## Ethernet

Plug a cable between your computer and MARS. Set your computer's Ethernet interface to IP `192.168.50.1`, netmask `255.255.255.0`, with no gateway or DNS. Then:

```bash
ssh jetson1@192.168.50.2
```

<AccordionGroup>
  <Accordion title="Set a static IP on macOS">
    **System Settings → Network → Ethernet → Details → TCP/IP**. Configure IPv4 manually with the values above and leave the router empty.
  </Accordion>
  <Accordion title="Set a static IP on Windows">
    **Settings → Network & Internet → Advanced network settings → More network adapter options**. Right-click **Ethernet → Properties → Internet Protocol Version 4**, choose manual, and enter the values above.
  </Accordion>
  <Accordion title="Set a static IP on Ubuntu">
    **Settings → Network → Wired**, click the gear, set IPv4 to manual with the values above, then toggle wired off and on.
  </Accordion>
</AccordionGroup>

## USB-C (recovery only)

Use this when the network is broken. Connect a cable to the Jetson's USB-C port, then:

```bash
ssh jetson1@192.168.55.1
```
