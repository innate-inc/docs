Start by making sure the robot is [up to date](/robots/mars/updates-and-maintenance#update-innate-os). Many problems are already fixed in a newer release.

## Common problems

| Problem | Fix |
| --- | --- |
| App reaches the robot but says services failed to launch | SSH in and run `sudo ~/innate-os/scripts/update/post_update.sh`, then reconnect. |
| Arm goes limp | Rest the arm, then **Configuration → Dev → Reboot Arm** in the app. If that fails, power-cycle the robot. |
| Arm feels weak | The overload protection lowered torque. Remove heavy objects or obstructions, then reboot the arm. |
| Leader arm doesn't work on iPhone | See the note below. |
| Agent or skill misbehaves | Follow [Debugging](/software/ros2/debugging). |
| Depth or obstacle avoidance looks wrong | Redo [stereo depth calibration](/robots/mars/stereo-depth-calibration). |
| Can't SSH | Try the IP instead of `.local`, or [Ethernet or USB-C](/robots/mars/connecting-via-ssh). |

## Read the logs

Open the web app's [Logging page](/robots/apps#logging), or SSH in and attach to the process session:

```bash
innate view
```

Each tmux pane runs a part of the stack. Look for red errors or panes that keep restarting. Switch windows with `Ctrl+B` then a number, scroll with `Ctrl+B` then `[`, and detach with `Ctrl+B` then `D`.

## Find your MARS ID

The number in the Bluetooth name is your ID: **MARS the 12th** is ID 12. Over SSH:

```bash
cat ~/innate-os-data/robot_info.json
```

<Note>
  Robots 1 to 11, shipped before January 2026, needed a one-time setup fix. If yours was never set up, contact us on Discord.
</Note>

## Get help

Ask on [Discord](https://discord.com/invite/KtkyT97kc7), where the team and other owners answer daily, or email [axel@innate.bot](mailto:axel@innate.bot). Include:

- your MARS ID and OS version (`innate update status`)
- the exact error message and the node it came from
- what you were doing when it happened
